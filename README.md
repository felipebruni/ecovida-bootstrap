# Landing Page - EcoVida (Sustentabilidade no Dia a Dia)

Projeto desenvolvido como atividade prática para a disciplina de Desenvolvimento Web, com uso do framework Bootstrap.

## 📌 Sobre o Projeto
A página foi construída com base nos temas da **Agenda 2030 (ODS)**, apresentando dicas práticas de sustentabilidade doméstica e um formulário para recebimento de guia informativo.

## 🛠️ Tecnologias Utilizadas
- HTML5
- Bootstrap 5.3 (via CDN oficial)

## 🧩 Componentes do Bootstrap Implementados
- **Navbar:** Barra de navegação responsiva.
- **Carousel:** Banner rotativo com imagens e legendas.
- **Cards e Sistema de Grid:** Três cards explicativos alinhados usando as classes responsivas.
- **Formulário:** Inputs de texto, email, select e checkbox estilizados com validação nativa.
